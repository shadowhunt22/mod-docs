## Configuration

> [!IMPORTANT]
> In order to access these options, you must install [ShadowHunter22's Config Library](https://modrinth.com/mod/shadowhunter22s-config-library)

## Keybinds

`H`: Enable/Disable Indicator

`K`: Open Config Menu

## Options

<div class="configuration-option">

### Enabled 

</div>

Type: `Boolean`

Values:
- True `default`
- False

<div class="configuration-option">

### Colored Indicator 

</div>

Type: `Boolean`

Values:
- True `default`
- False

<div class="configuration-option">

### Indicator Position 

</div>

Type: `Enum`

Values:
- Left `default`
- Right

<div class="configuration-option">

### Number Type 

</div>

Type: `Enum`

Values:
- Integer 
- Decimal `default`
