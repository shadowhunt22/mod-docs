## Configuration

> [!IMPORTANT]
> In order to access these options, you must install [ShadowHunter22's Config Library](https://modrinth.com/mod/shadowhunter22s-config-library)

## Keybinds

`O`: Enable/Disable HUD

`I`: Open Config Menu

## Options

### HUD Options

<div class="configuration-option">

#### HUD Enabled

</div>

Type: `Boolean`

Values:
- True `default`
- False 

<div class="configuration-option">

#### HUD Location

</div>

Type: `Enum`

Values:
- Top Left `default`
- Top Right 
- Bottom Left 
- Bottom Right 

<div class="configuration-option">

#### HUD Scale

</div>

Type: `Float`

Values:
- Min: 0.5
- Max: 1.0
- `default`: 0.75

### Misc. Options

<div class="configuration-option">

#### Always Shown

</div>

Type: `Boolean`

Values:
- True 
- False `default`

<div class="configuration-option">

#### Render Enchanted Book

</div>

Type: `Boolean`

Values:
- True `default`
- False
